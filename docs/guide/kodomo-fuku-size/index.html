子ども服のサイズ早見表｜
年齢・身長別に80〜130cmの目安を解説

子ども服の80・90・100・110・120・130は、まず身長を基準に選びます。年齢は便利な目安ですが、同じ年齢でも体格はさまざま。下の早見表で候補を確認し、今着ている服と商品の実寸も合わせて見てください。

表の出典と、メーカーによる目安の違い

身長区分は、一般財団法人カケンテストセンターが掲載する乳幼児用、少年用、少女用のJIS抜粋と、無印良品公式を参照しています。年齢は無印良品と西松屋公式のアウトウェア目安をもとにしました。

年齢の示し方はメーカーや商品で異なります。たとえば110サイズを「4〜6歳」の目安とする公式表がある一方、ユニクロ公式の商品ページのように「4〜5歳」とする例もあります。年齢欄は購入サイズを決める基準ではなく、候補を探すための目安としてご覧ください。

サイズ表を見るときのポイント

「100＝4歳」と決まっているわけではありません。 JISの子ども服サイズ表示では、身長・体重・胸囲・ウエストなどの「着る人の身体寸法」を基準にします。100は服そのものの長さでも、4歳専用という意味でもありません。まず現在の身長と体格を見て、最後に商品ごとの実寸を確認しましょう。

来年のサイズまで知りたい方へ半年後・1年後に着る服は、今の早見表だけでは決めにくくなります。

子ども服のサイズは「年齢」よりまず身長を見る

「3歳なら100」「4歳なら110」のような年齢の目安は、売り場や通販で候補を絞るときに便利です。ただし、同じ年齢でも身長や体格は一人ひとり違います。サイズ表を見る順番は、年齢から候補を知る → 現在の身長と体格で絞る → 商品の実寸で確かめる、と考えると分かりやすくなります。

カケンテストセンターが紹介するJIS L 4001・4002・4003:2023の表示例でも、乳幼児用は身長と体重、少年・少女用は服の種類に応じて身長、胸囲、ウエストなどの身体寸法を使います。年齢は基本身体寸法として示されていません。

さらに、タグのサイズと服の仕上がり寸法は別のものです。GUの公式サイズ案内では、「商品サイズ」は実際に商品を測った寸法、「ヌード寸法」は服を着ていない身体の寸法と説明し、同じサイズ記号でもデザインによって着用感が異なると案内しています。購入先の商品ページに着丈・身幅・袖丈・股下があれば、手持ちの服と比べてみましょう。

80・90・100・110・120・130サイズは何歳？

ここでは、公式サイズ表の目安を短くまとめます。年齢よりも、各欄の身長と現在の着用感を優先してください。

80サイズは何歳？

メーカー例では1歳〜1歳半ごろ、身長75〜85cmが目安です。JISの乳幼児用「80」は身長80cm・体重11kgの表示例です。

90サイズは何歳？

メーカー例では1歳半〜2歳半ごろ、身長85〜95cmが目安です。2歳前後でも、身長と服のゆとりを確認します。

100サイズは何歳？

メーカー例では3〜4歳ごろ、身長95〜105cmが目安です。「4歳なら必ず100」ではなく、現在の身体寸法から選びます。

110サイズは何歳？

メーカー例では4〜6歳ごろ、身長105〜115cmが目安です。メーカーによって年齢幅が異なるため、袖や裾の長さも確認します。

120サイズは何歳？

メーカー例では6〜7歳ごろ、身長115〜125cmが目安です。パンツは身長だけでなく、ウエストと股下も確認しましょう。

130サイズは何歳？

メーカー例では8〜9歳ごろ、身長125〜135cmが目安です。同じ身長帯でも体格や好みのフィット感で選択は変わります。

同じ年齢でも着るサイズが違うのはなぜ？

同じ3歳・4歳・5歳でも、合う子ども服のサイズが違うのは自然なことです。サイズ選びには、次のような要素が重なります。

  • 現在の身長
  • 胸まわりやウエストなどの体格
  • 腕や脚の長さ
  • ブランドごとの寸法
  • 細身・標準・ゆったりなどのシルエット
  • 好みのフィット感
  • これまでの成長のペース

たとえば身長が同じでも、パンツはウエストや股下、トップスは肩幅や袖丈によって着用感が変わります。また、その子自身の成長の仕方も同じではありません。年齢欄と違うサイズを着ていても、服選びでは無理なく動けるか、きつい部分や余りすぎる部分がないかを見れば大丈夫です。

ちょうどいいサイズを選ぶ3つのポイント

① 現在の身長を確認する

最近測った身長を、表の身長帯と照らし合わせます。しばらく測っていなければ、購入前に測り直すと候補を絞りやすくなります。

② 今着ている服のフィット感を見る

袖丈、裾、肩、ウエスト、動きやすさを確認します。「今100」だけでなく、余裕があるか、小さくなり始めたかまで見ます。

③ 商品ごとの実寸を確認する

同じ100・110でも仕上がり寸法は商品ごとに異なります。着丈・身幅・袖丈・股下を、手持ちの服と比べます。

手持ちの服で見る場所
  • トップス：肩が落ちすぎないか、袖や着丈が短くないか
  • パンツ：ウエストがきつくないか、裾を引きずらないか
  • 共通：腕を上げる、しゃがむ、歩くなどの動きを妨げないか

子ども服はワンサイズ上を買った方がいい？

常にワンサイズ上が正解とは限りません。今すぐ着る服なら、まず現在の身体サイズに合う候補を見ます。少しゆとりを持たせる場合も、服の種類によって使いやすさが変わります。

Tシャツ

大きすぎると首まわりや脇が開きやすく、着丈も長くなります。

パンツ

ウエストのずれ、股下の長さ、裾を踏まないかを優先します。

アウター

重ね着分の余裕は必要ですが、袖が長すぎないか確認します。

パジャマ

袖や裾が余りすぎず、寝返りや歩行を妨げないサイズを選びます。

園服・通園着

園の指定や着脱のしやすさ、活動時の動きやすさも確認します。

大きめを買うこと自体が悪いわけではありません。着る時期、必要なゆとり、調節できるウエストや袖口の有無まで見て、無理なく着られる範囲で選びましょう。

来年用・セールの先買いなら考え方が変わる

半年後・1年後に着る服は、現在のサイズ表だけでは判断しにくくなります。「今100だから次は110」と決めるのではなく、実際に着る季節までの期間と、その子自身のこれまでの成長の推移も確認します。

子ども服のサイズについてよくある質問

Q. 3歳は何サイズ？

メーカー例では100サイズが3〜4歳の目安ですが、年齢だけでは決められません。現在の身長を測り、95〜105cmの目安に当てはまるか、今の服にどのくらい余裕があるかを確認してください。

Q. 4歳は100と110どちら？

100は身長95〜105cm、110は105〜115cmがひとつの目安です。現在の身長・体格を確認し、購入商品の実寸と手持ちの服を比べます。4歳という年齢だけでどちらかに決める必要はありません。

Q. 5歳は何サイズ？

メーカー例では110サイズが候補になりますが、身長105〜115cmの範囲を目安に考えます。トップスなら袖丈、パンツならウエストと股下など、服の種類に合った寸法も確認しましょう。

Q. 100サイズは何歳まで着られる？

「何歳まで」と一律には決められません。身長や体格、服の作り、好みのフィット感によって変わります。袖や裾が短い、ウエストがきつい、動きにくいなどのサインを見て判断します。

Q. 子ども服のサイズ数字は身長のこと？

国内のJISに沿った表示例では、80・100などの呼び方は着る人の身長を基準にした区分です。たとえば少年・少女用の100は身長95〜105cmの範囲表示があります。ただし、数字は服そのものの長さではありません。胸囲・ウエストなどの身体寸法や、商品ごとの仕上がり寸法も確認してください。

Q. 年齢とサイズ表が合わないときはどうする？

年齢欄ではなく、現在の身長や体格を優先して候補を選びます。そのうえで、今着ている服のフィット感と商品の実寸を比べてください。年齢の目安と違うサイズを着ていることだけで、医学的な問題を判断するものではありません。

まとめ｜年齢は目安、まずは今の身長から

  1. 年齢別サイズは、候補を探すための便利な目安
  2. まず現在の身長と体格を見る
  3. 購入前に商品ごとの仕上がり寸法を確認する
  4. 来年用なら、その子自身の成長の推移も考える

子供服のサイズ表は、年齢から答えを決めるものではなく、今の身体寸法に合う候補を見つけるための入口です。年齢 → 身長 → 今の体格 → 商品実寸の順に確認し、未来の服なら成長記録も判断材料に加えましょう。
