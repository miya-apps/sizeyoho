まず読みたいガイド

サイズ選びの基本や、よく迷いやすいテーマを4本に絞って紹介します。

子ども服

サイズ早見表から、90・100・110サイズ、大きめ・ジャスト、来年用の選び方まで。

靴

年齢別サイズや測り方から、サイズアップの時期と買い替えサインまで。

おむつ

公開済みの記事が増えた段階で、ここにカテゴリ別に整理します。記事の代わりになるダミーカードは置いていません。

  • 体重別の目安
  • サイズアップ
  • 漏れ・跡
  • メーカー比較

身長・成長

公開済みの記事が増えた段階で、ここにカテゴリ別に整理します。今は今後扱うテーマだけを示しています。

  • 平均身長・体重
  • 成長曲線
  • SDスコア
  • 成長記録

サイズ選びを、もっとラクに

毎回自分で調べる代わりに、サイズ予報なら、お子さまの成長記録から服・靴・おむつの目安を確認できます。
